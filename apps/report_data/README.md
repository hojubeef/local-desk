# 보고서 기초자료 모듈

상하수도 관련 보고서의 기초조사 항목별로 KOSIS 후보 통계표를 추천하는 별도 모듈입니다.

## 원칙

- 기존 KOSIS 화면 위에 기능을 얹지 않고 별도 화면으로 유지합니다.
- 검색과 자료조회는 `apps/kosis/kosis_client.py`를 재사용합니다.
- 자동 추천 범위는 우선 좁게 둡니다.
  - 선택한 시/군 기관별 통계
  - 상수도·하수도 주요기관 통계
  - 후보가 없으면 수동 검색 필요

## 주요 파일

- `report_items.json` — 보고서별 기초자료 항목 초안
- `report_data_service.py` — 항목별 후보 추천 로직

## 주의

`report_items.json`의 항목은 1차 초안입니다. 지침 원문 세부 표와 완전히 일치한다고 단정하지 말고, 후보 통계표의 메타데이터와 미리보기 자료를 확인한 뒤 사용해야 합니다.
