# 🗂️ KOSIS 통계 조회 도구 v2

원하는 지역의 KOSIS 통계표를 검색하고, 행정구역별 폴더 트리로 한눈에 확인할 수 있는 데스크탑 프로그램입니다.

---

## ✨ v2 새로운 기능

- **폴더 트리 구조**: 검색 결과를 전국/시도/시군구별로 자동 분류
- **매칭 경로 표시**: 통계표명/분류항목/키워드 중 어디서 매칭됐는지 태그 표시
- **기관 수준 구분**: 전국 기관(환경부 등) vs 지역 기관(상주시 등) 구분
- **중복 폴더**: 여러 행정구역에 걸친 통계표를 별도 표시
- **프로그레스바**: 분석 진행률 실시간 표시
- **지역지표 보강 검색**: KOSIS 통합검색에 e-지방지표(주제별) 목록과 지역 메타 확인을 추가
- **추천도 기반 검색**: 단순 검색어를 내부 확장 검색하고, 지역수준/세부분류/최신시점으로 후보를 정렬
- **3개 병렬 확장검색**: 통합검색 후보 수집은 최대 3개씩 병렬 호출해 대기시간을 줄임
- **트리형 조건 선택**: KOSIS처럼 항목/분류값을 트리에서 선택하고 필요한 데이터만 미리보기
- **세분화 수준 요약**: 통계표가 시군구/읍면동/연령/성별 등 어디까지 내려가는지 표시

## 📦 설치 및 실행

### 1. Python 3.9 이상 설치
### 2. 라이브러리 설치
```
pip install PublicDataReader
```
### 3. API 키 설정
새 PC에서는 `config.example.py`를 `config.py`로 복사한 뒤
`"여기에_본인_API키_입력"` 부분을 본인 키로 교체

### 4. 실행
```
python app.py
```
