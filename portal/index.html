Guide

                
새 PC 세팅

              

            

            
clone 후 아래 파일들은 Git에 안 올라가므로 직접 설정해야 합니다.

            

              
1. KOSIS API 키

              apps/kosis/config.example.py → apps/kosis/config.py로 복사 후 API 키 입력

              
2. Google Calendar

              Google OAuth JSON 파일을 local/secrets/google-calendar-credentials.json에 저장

              달력 화면에서 '연결' 누르면 토큰이 자동 생성됨

              
3. 새 앱 추가 시

              API 키가 필요하면 config.example 파일을 만들고, 실제 키 파일은 .gitignore에 추가
