# 야근일지

채팅창에 쓰던 야근일지 형식을 그대로 붙여넣어 저장하고, 공유 드라이브의 직원별 폴더를 수집해 월별/직원별 집계를 확인하는 Windows용 단독 앱입니다.

상세 개발 규칙과 AI 작업 가이드는 [SPEC.md](./SPEC.md)를 참고하세요.

## 주요 기능

- 채팅 형식 야근일지 파싱 및 저장
- 내 월별 합계, 주간 합계, 달력 보기
- 직원별 현황 보기
- 전체 집계, CSV 내보내기
- 출퇴근 기록 기준 확인 필요 표시
- 대리 입력, 대리 수정/삭제, 휴지통
- 결재 올림, 올림 취소, 결재 완료 목록 비교
- 개인/관리자 백업 및 복원
- 컴퓨터 시작 시 자동 실행 설정
- 어두움/밝음 화면 테마
- 대리 입력 및 관리자 기능 표시 설정

## 실행

개발용으로 실행할 때:

```text
야근일지 실행.bat
```

또는 Python으로 직접 실행:

```text
python server.py
```

실행하면 브라우저에서 로컬 주소가 열립니다. 기본 주소는 `http://127.0.0.1:8877`이며, 포트가 사용 중이면 자동으로 다른 포트를 사용합니다.

## 배포

직원 PC에는 빌드된 EXE만 전달하면 됩니다.

```text
dist\야근일지_수정본8.exe
```

직원들은 Python이나 PyInstaller를 설치할 필요가 없습니다. PyInstaller는 EXE를 만드는 PC에만 필요합니다.

## EXE 빌드

PyInstaller가 설치되어 있으면 아래 배치 파일로 빌드합니다.

```text
build_exe.bat
```

수동 빌드 예시:

```text
python -m PyInstaller --noconfirm --noconsole --onefile --name "야근일지" --add-data "web;web" server.py
```

빌드 결과는 `dist/` 폴더에 생성됩니다.

## 권장 데이터 구조

공유 드라이브 또는 웹하드의 데이터 루트 아래에 직원별 폴더를 둡니다.
설정에서는 이호중 웹하드의 `00.야근일지` 폴더만 데이터 루트로 선택하면 됩니다.
프로그램이 설정의 이름과 같은 직원 폴더를 찾아 그 안의 `야근일지` 폴더에 저장합니다.

```text
데이터루트
├─ 이호중
│  └─ 야근일지
├─ 박원준
│  └─ 야근일지
└─ 노용주
   └─ 야근일지
```

각 직원이 저장한 야근일지는 다음 구조로 저장됩니다.

```text
데이터루트\직원이름\야근일지\
  entries\
    2026-05\
      2026-05-06_1800_2000_직원이름_xxxxx.json
  backups\
  trash\
```

## 입력 형식

기존 채팅 입력 형식을 그대로 사용합니다.

```text
2026.05.06(수) 18:00~20:00
2026년도 하수도 맨홀추락방지시설 설치공사(3차) 도면 작업
```

대리 입력 모드에서는 직원 이름 줄을 먼저 씁니다.

```text
이호중
2026.05.06(수) 18:00~20:00
2026년도 하수도 맨홀추락방지시설 설치공사(3차) 도면 작업
```

## 출퇴근 기록

출퇴근 기록 폴더에는 `Export_YYYYMMDD.txt` 같은 파일을 넣어둡니다.

- `1` = 출근
- `2` = 퇴근
- 같은 날짜에 출근을 여러 번 찍으면 가장 빠른 시간 사용
- 같은 날짜에 퇴근을 여러 번 찍으면 가장 늦은 시간 사용
- 퇴근 시간이 확인 기준 이후인데 야근일지가 없으면 `확인 필요`로 표시

## 설정 저장 위치

프로그램 설정은 각 PC의 AppData에 저장됩니다.

```text
%APPDATA%\OvertimeJournal\settings.json
```

야근일지 데이터 자체는 설정 파일이 아니라 사용자가 선택한 데이터 루트 폴더 아래에 저장됩니다.

## 폴더 구조

```text
web/                 브라우저 화면 HTML/CSS/JS
server.py            로컬 HTTP 서버 및 API
service.py           야근일지 저장, 파싱, 수집, 백업 로직
docs/                사용자 설명서
dist/                PyInstaller 빌드 결과물
build/               PyInstaller 임시 빌드 폴더
build_exe.bat        EXE 빌드 스크립트
야근일지 실행.bat    개발용 실행 스크립트
```

## Git 관리 권장

KOSIS/Local Desk 저장소 안에서 같이 관리하더라도 이 앱은 별도 단독 앱으로 봅니다.
야근일지 작업을 할 때는 이 폴더의 `README.md`와 `SPEC.md`를 기준으로 보고, KOSIS나 포털 작업 규칙과 섞지 않습니다.

Git에는 소스와 문서만 올리고, 아래는 제외하는 것이 좋습니다.

- `build/`
- `dist/`
- `__pycache__/`
- `.edge-print-profile/`
- `*.spec`
- 실제 회사 데이터가 들어있는 공유 드라이브 폴더

소스와 문서만 관리하고, EXE는 필요할 때 다시 빌드하는 방식이 가장 깔끔합니다.
