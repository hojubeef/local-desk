# 야근일지 단독 앱

채팅창에 쓰던 야근일지 형식을 그대로 붙여넣고, 각자 선택한 웹하드/공유드라이브 폴더에 JSON 파일로 저장하는 단독 앱입니다.

## 실행

```text
야근일지 실행.bat
```

실행하면 로컬 주소가 열립니다. 기본 주소는 `http://127.0.0.1:8877`이며, 포트가 사용 중이면 자동으로 다른 포트를 사용합니다.

## 저장 구조

```text
선택한폴더\야근일지\
  entries\
    2026-05\
      2026-05-06_1800_2000_홍길동_xxxxx.json
```

수정한 야근일지는 같은 JSON 파일 안의 `history` 배열에 이전 값과 수정 후 값이 남습니다. 관리자 집계 화면의 원본 기록 표에서 수정 횟수를 볼 수 있습니다.

## 출퇴근 기록 확인

출퇴근 기록 폴더에는 `Export_YYYYMMDD.txt` 같은 파일을 넣어두면 됩니다. 앱은 `1=출근`, `2=퇴근`으로 읽고, 같은 날짜에 여러 번 찍힌 경우 출근은 가장 빠른 시간, 퇴근은 가장 늦은 시간을 사용합니다.

퇴근 시간이 확인 기준 이후인데 야근일지가 없으면 달력과 전체 집계 화면에 `확인 필요`로 표시합니다.

## 배포

Python이 있는 PC에서는 이 폴더를 그대로 복사해서 실행할 수 있습니다.

직원 PC에 Python이 없으면 `build_exe.bat`로 `dist\야근일지.exe`를 만든 뒤 배포합니다. 빌드 PC에는 PyInstaller가 필요합니다.
