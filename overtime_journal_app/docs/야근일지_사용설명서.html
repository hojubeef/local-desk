야근일지 사용설명서

각 직원이 자기 PC에서 야근일지를 입력하고, 공유 드라이브 데이터 루트에서 관리자 집계를 확인하는 단독 프로그램입니다.

배포 파일: 야근일지_수정본8.exe 작성일: 2026-05-08 대상: 직원 입력 / 관리자 집계

1. 프로그램 개요

이 프로그램은 기존 채팅창에 적던 야근일지 형식을 그대로 사용합니다. 직원은 날짜, 시간, 업무내용을 적어 저장하고, 관리자는 데이터 루트 폴더 안의 직원별 기록을 수집해서 월별 합계, 달력, 결재 상태, 누락 여부를 확인합니다.

직원이 하는 일

  • 자기 이름과 데이터 루트 폴더를 설정합니다.
  • 빠른 입력에서 야근일지를 붙여넣고 저장합니다.
  • 내 현황에서 월별 합계, 달력, 수정/삭제를 확인합니다.

관리자가 하는 일

  • 수집할 직원과 직급을 설정합니다.
  • 전체 집계에서 기록을 수집하고 정렬된 목록을 확인합니다.
  • 결재 올림, 결재 완료 비교, 백업/복원을 처리합니다.

2. 권장 폴더 구조

데이터는 한 루트 폴더 아래에 직원 이름별로 모으는 방식이 가장 관리하기 쉽습니다.

데이터루트
├─ 이호중
│  └─ 야근일지
├─ 박원준
│  └─ 야근일지
└─ 노용주
   └─ 야근일지

직원이 저장하면 각 직원 폴더 안에 야근일지\entries가 만들어지고, 수정/삭제 이력과 백업 파일도 그 아래에 남습니다.

배포할 때 직원 PC에는 보통 야근일지_수정본8.exe만 전달하면 됩니다. Python이나 PyInstaller를 각 직원이 따로 설치할 필요는 없습니다.

3. 처음 설정

  1. 야근일지_수정본8.exe를 실행합니다. 브라우저가 열리면 프로그램 화면이 표시됩니다.
  2. 설정 탭으로 이동합니다.
  3. 이름에 본인 이름을 입력합니다. 데이터 루트 안의 폴더명과 같게 입력하는 것이 좋습니다.
  4. 데이터 루트 폴더에서 공유 드라이브의 최상위 폴더를 선택합니다.
  5. 수집 직원 선택에서 집계할 직원을 체크하고, 필요한 경우 직급을 지정합니다.
  6. 컴퓨터를 켤 때 자동 실행하려면 컴퓨터 켤 때 자동 실행을 체크합니다.
  7. 설정 저장을 누릅니다.
설정 항목 설명
이름 내 기록을 저장할 직원명입니다. 예: 이호중
데이터 루트 폴더 직원별 폴더가 들어있는 최상위 공유 폴더입니다.
수집 직원 선택 관리자가 전체 집계에서 가져올 직원만 체크합니다. 이 부분은 접기/펼치기가 가능합니다.
직급 전무, 상무, 이사, 차장, 과장, 대리, 사원 순서로 정렬에 사용됩니다.

4. 빠른 입력

기존 채팅 입력 방식 그대로 붙여넣으면 됩니다. 한 건은 날짜/시간 줄과 업무내용 줄로 구성됩니다.

2026.05.06(수) 18:00~20:00
2026년도 하수도 맨홀추락방지시설 설치공사(3차) 도면 작업
  1. 빠른 입력 탭에서 내용을 붙여넣습니다.
  2. 필요하면 왼쪽 달력에서 날짜를 눌러 기본 시간 문장을 넣습니다.
  3. 미리보기를 눌러 날짜, 시간, 업무내용이 맞게 인식됐는지 확인합니다.
  4. 이상이 없으면 저장을 누릅니다.
편한 입력 방법 과업명과 최근 업무내용 버튼을 누르면 자주 쓴 문장을 바로 넣을 수 있습니다. 출퇴근 기록 폴더를 설정해두면 늦은 퇴근 시간도 빠른 입력에서 참고할 수 있습니다.

5. 출퇴근 기록 확인

출퇴근 기록 폴더를 등록하면, 퇴근 기록은 있는데 야근일지가 없는 날짜를 확인 필요로 표시합니다.

  • 출퇴근 기록은 Export_YYYYMMDD.txt 같은 파일을 읽습니다.
  • 1은 출근, 2는 퇴근으로 처리합니다.
  • 출근을 여러 번 찍으면 가장 빠른 시간, 퇴근을 여러 번 찍으면 가장 늦은 시간을 사용합니다.
  • 퇴근 시간이 확인 기준 이후인데 야근일지가 없으면 달력과 집계 화면에 표시됩니다.
옵션 기본값 / 의미
확인 기준 기본 18:30. 이 시간 이후 퇴근이면 확인 대상으로 봅니다.
야근 시작 기본 18:00. 자동 초안의 시작 시간으로 사용합니다.
이번 달 전 확인 필요 숨김 지난달 이전 알림을 숨겨 화면을 깔끔하게 봅니다.
출근/퇴근 기록 없음 무시 출근만 찍거나 퇴근만 찍은 자료를 어떻게 볼지 정합니다.

6. 내 현황

내 현황 탭에서는 내 월별 합계, 주간 합계, 달력, 기록 목록을 확인합니다. 달력에서 날짜를 누르면 해당 날짜의 기록을 바로 볼 수 있고, 기록 옆의 수정 또는 삭제로 정리할 수 있습니다.

  • 하루 3시간, 주 12시간, 월 20시간 기준을 넘으면 알림이 표시됩니다.
  • 야간시급을 입력하면 참고용 수당 계산을 볼 수 있습니다.
  • 수정하면 수정 이력이 남아 관리자 화면에서도 확인할 수 있습니다.

7. 대리 입력 모드

한 사람이 여러 직원의 야근일지를 대신 입력해야 할 때 사용합니다.

  1. 빠른 입력에서 대리 입력 모드를 켭니다.
  2. 직원 퇴근 확인을 누르면 수집 직원 기준으로 출퇴근 기록을 확인합니다.
  3. 확인 필요 항목의 초안 넣기를 누르면 직원 이름이 포함된 입력 초안이 들어갑니다.
  4. 업무내용을 확인한 뒤 미리보기와 저장을 진행합니다.

8. 직원별 현황

직원별 현황 탭에서는 수집된 직원 중 한 명을 선택해 내 현황과 비슷한 형태로 볼 수 있습니다. 직원별 월 합계, 주간 합계, 달력, 제한시간 알림, 기록 목록을 확인할 수 있고 필요하면 수정/삭제도 가능합니다.

9. 전체 집계

전체 집계는 관리자가 가장 자주 보는 화면입니다. 수집을 누르면 설정에서 체크한 직원의 기록만 가져옵니다.

결재 올림 수집된 기록에서 체크 후 선택 결재 올림을 누릅니다. 잘못 올린 것은 선택 올림 취소로 되돌립니다.

11. 자주 헷갈리는 부분

직원들도 PyInstaller를 받아야 하나요?

아니요. 빌드된 야근일지_수정본8.exe만 실행하면 됩니다. PyInstaller는 EXE를 만드는 PC에만 필요합니다.

EXE만 전달하면 되나요?

일반 직원에게는 EXE만 전달하면 됩니다. 데이터는 공유 드라이브의 데이터 루트에 저장되고, 개인 설정은 각 PC의 AppData에 저장됩니다.

수집 직원이 안 보이면?

데이터 루트 폴더 바로 아래에 직원 이름 폴더가 있는지 확인한 뒤, 설정 탭의 수집 직원 선택에서 새로고침을 누릅니다.

출퇴근 기록이 있는데 확인 필요가 안 뜨면?

출퇴근 기록 폴더가 등록되어 있는지, 파일 안의 이름이 직원 폴더명과 맞는지, 퇴근 시간이 확인 기준 이후인지 확인합니다.

브라우저를 닫으면 프로그램도 꺼지나요?

현재 버전은 브라우저 창을 닫으면 서버도 같이 종료되도록 구성되어 있습니다. 다시 사용하려면 EXE를 다시 실행하면 됩니다.

운영 추천 처음에는 직원 1~2명으로 실제 입력, 수정, 삭제, 결재 올림, 결재 완료 비교까지 한 번씩 테스트한 뒤 전체 직원에게 배포하는 게 좋습니다.
